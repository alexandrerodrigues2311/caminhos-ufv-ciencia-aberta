# Caminhos UFV — versão 4.2

Abra caminhos-ufv-v4.ipynb no Colab. O caderno contém código integral, leitura de dados, filtros, descrição, ML, GEE, interação exploratória, gráficos, rede, mapa e manifesto. Inicia com 400 registros inteiramente fictícios.

Para dados privados, preencha o identificador de sua própria planilha e autentique sua conta no Colab; não publique as saídas privadas. Os dados sintéticos não representam participantes ou estimativas da UFV. Não misture versões do instrumento. Mediação causal não é estimada. Os arquivos anteriores foram preservados para consulta.
